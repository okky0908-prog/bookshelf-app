# 要件定義書：読書記録アプリ（本棚アプリ）

## 1. 概要

個人の読書記録を管理する、シンプルな本棚Webアプリケーション。
スクール課題（初級編最終課題）として開発する。

## 2. 背景・目的

- スクールの初級編最終課題として取り組むものであり、特定の業務課題やビジネス上の目的があるわけではない
- 主目的は学習：指定技術スタック（Next.js / Ruby on Rails / MySQL）での要件定義〜設計〜実装という開発の一連の流れを一人で経験し、身につけること
- 副次的な狙いとして、実際に自分の読書記録に使えるものを作ることで、成果物としての実用性・学習の定着度を高める

## 3. 想定利用者

- 開発者本人のみ（1ユーザー）
- ログイン・認証機能は不要（前回のTrello風アプリと同様の方針を踏襲）

## 4. スコープ

### 4.1 今回実装する範囲（MVP）

- 書籍の登録・編集・削除
- ステータス管理（未読／読書中／読了）と、カンバンのカラム移動と同様のドラッグ&ドロップによるステータス変更
- 読了時の完了日入力
- 1ヶ月単位の読書量集計（指定月の読了冊数＋直近12ヶ月の月別読了冊数グラフ）
- 評価（星1〜5）・感想メモの記録（書籍1件につき1件のシンプルな形）

### 4.2 将来的に追加したい範囲（今回は対象外）

- 感想メモを複数回に分けて記録できる「フィード」形式への拡張（読書中の途中経過メモを都度追加できる等）
- 書籍の検索・タグ・ジャンル分類
- 複数の本棚（カテゴリ別の本棚切り替え）
- ログイン・複数ユーザー対応

### 4.3 明確に対象外とするもの

- 他ユーザーとの読書記録の共有・SNS的機能
- 書影・書誌情報の外部API（Google Books等）からの自動取得

## 5. 機能要件

書籍を1件のリソースとして登録し、ステータス（未読／読書中／読了）で管理する。ステータス変更はカンバン風のドラッグ&ドロップUIで行う。読了時には完了日を入力できる。月ごとの読了冊数を集計して表示する。評価・感想メモは書籍ごとに1件記録できる。

### 5.1 書籍の登録項目

| 項目 | 必須 | 内容 |
|---|---|---|
| タイトル | ○ | テキスト |
| 著者名 | － | テキスト |
| 書影画像URL | － | 手入力したURLの画像をカードに表示する（外部APIからの自動取得はしない）。未入力時はプレースホルダ表示 |
| ステータス | ○ | 未読／読書中／読了。新規登録時の初期値は「未読」 |
| 読書開始日 | － | 日付。「読書中」への移動時に自動セット（後述） |
| 完了日 | － | 日付。「読了」への移動時に自動セット（後述） |
| 評価 | － | 1〜5の整数（星5段階）。ステータスが「読了」の書籍のみ入力可。未評価も可 |
| 感想メモ | － | 自由記述テキスト。ステータスに関係なく入力可 |

### 5.2 書籍の登録・編集・削除

- 本棚ボード画面から新規登録できる。登録した書籍は「未読」列の末尾に追加する
- カードを選択すると編集モーダルが開き、上記すべての項目を編集できる
- 編集モーダルから削除できる。削除前に確認ダイアログを表示する

### 5.3 ステータス管理（ドラッグ&ドロップ）

- ボードは「未読」「読書中」「読了」の3列で構成する
- カードを列間でドラッグ&ドロップするとステータスが変わる
- 同じ列の中でもドラッグ&ドロップで自由に並べ替えでき、並び順は保存される（再読み込み後も維持）
- ステータス変更時の日付・評価の扱いは以下のとおり

| 移動 | 読書開始日 | 完了日 | 評価 |
|---|---|---|---|
| → 読書中 | 未入力なら今日の日付を自動セット | クリア | クリア |
| → 読了 | 変更しない | 今日の日付を自動セット | 変更しない（読了後に入力） |
| → 未読 | クリア | クリア | クリア |

- 自動セットされた日付は、編集モーダルで後から任意の日付に修正できる
- 感想メモはステータスが変わってもクリアしない
- 「未読」から「読了」へ直接移動した場合、読書開始日は未入力のままとする

### 5.4 月間読書量集計

- 集計対象は、ステータスが「読了」で完了日が入力されている書籍とする。完了日の年月で集計する
- 指定月の読了冊数を表示する。初期表示は今月とし、前月／翌月に切り替えられる
- 直近12ヶ月（今月を含む）の月別読了冊数を棒グラフで表示する。読了0冊の月も0として表示する

### 5.5 評価・感想メモ

- 評価・感想メモは書籍1件につき1件とし、編集モーダルから入力・更新する
- 評価は「読了」の書籍のみ入力でき、読了以外へ戻すとクリアされる（5.3参照）

## 7. 非機能要件

- 対応端末：PCのみ（デスクトップブラウザ。最新版のChromeで動作確認する）。スマートフォン・タッチ操作には対応しない
- 動作環境：ローカル環境のみ。Docker（docker compose）でフロントエンド・バックエンド・MySQLを起動する。本番環境へのデプロイは行わない
- 利用者：1ユーザー（開発者本人）。認証なしのため、外部公開はしない前提とする
- 性能：個人利用の規模（書籍数百件程度）で操作が快適に行えること
- データ保全：データはMySQLに永続化し、コンテナを再起動しても消えないこと
