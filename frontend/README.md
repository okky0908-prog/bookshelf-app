# frontend

本棚アプリのフロントエンド（Next.js 16 / App Router）。起動方法はリポジトリ直下の [README](../README.md) を、構成は [技術スタック詳細](../docs/tech-stack.md) を参照。

| コマンド            | 内容                                            |
| ------------------- | ----------------------------------------------- |
| `npm run dev`       | 開発サーバーを起動する（http://localhost:3000） |
| `npm run lint`      | ESLint でチェックする                           |
| `npm run typecheck` | TypeScript の型チェックを行う                   |
| `npm test`          | Vitest でテストを実行する                       |
| `npm run format`    | Prettier で整形する                             |
